## What's new

- Install from a single command in the Proxmox node shell. The installer creates an unprivileged Debian LXC and downloads the tested image without requiring a GitHub account.
- Open **Updates** at the bottom of the dashboard sidebar to see the installed version, read the release notes and copy an update command for the existing LXC. The updater waits for a healthy dashboard and stops before interrupting any active job.
- Use **Resources → Backup & restore** to download a passphrase-encrypted recovery copy or transfer selected scripts, labs and reusable builds to another cluster.
- Proxmate's source and installation scripts are available under the MIT License.

## Upgrading from v0.6.0

Back up the dashboard CT and separately mounted data before updating. Run the update command as root inside the existing CT. Check Inventory and a saved definition after signing in. For a complete rollback, restore the matching pre-update CT backup.
